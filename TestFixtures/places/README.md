# Places Benchmark Fixture

`places_desert_canyon.png` is the default visual input for the portable `ft_places2` benchmark scripts. It is a clean crop from the upstream Moebius Places showcase image:

`Moebius-Code/assets/sup_showcase_places_v2.png`

`places_desert_canyon_mask.png` is a simple sky-region mask generated for this repo. The benchmark scripts still accept `--image` and `--mask` when a different fixture is needed.
